# Finance-Banking-Dashboard

A clean finance and banking dashboard built as a static web app. It includes summary KPI cards, monthly revenue bars, portfolio allocation, and recent transactions.

## Run locally

From the project folder, start a simple local web server:

```bash
cd Finance-Banking-Dashboard
python3 -m http.server 3000
```

Then open:

```text
http://localhost:3000
```

## Files

- `index.html` – dashboard structure
- `styles.css` – styling and layout
- `app.js` – dynamic dashboard data rendering

## Notes

This version is dependency-free and works without installing npm packages, making it easy to run in a clean environment.
